## How to use the tracker

Open `Progress_Tracker.csv` in Excel (or import it into Power BI — a nice first exercise). Update
`Status`, dates and scores as you work. Status values used: `Not started`, `In progress`, `Blocked`,
`Done`.

Rules that make the tracker honest:

- A module is `Done` only when the **lab expected-results table matches**.
- A capstone is `Done` only when the **rubric score is 70 or more**.
- `Blocked` for more than two sessions means you stop and fix the foundation — usually a modelling
  problem in Module 3 or a context problem in Module 4, not the topic you are stuck on.

Target schedule: **8 weeks** at ~4 hours per weekday, or **16 weeks** at ~10 hours per weekend.
