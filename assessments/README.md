# assessments/ — prove you learned it

| File | What it is | When to use it |
|---|---|---|
| [`Quiz_Questions.md`](Quiz_Questions.md) | 60 questions (5 per module) with a full answer guide | At the end of each module, before moving on |
| [`Practical_Assessments.md`](Practical_Assessments.md) | Three timed exams with rubrics and expected figures — modelling & DAX (4h), forensic analytics (5h), advisory proposal (2h) | After Modules 5, 10 and 12 |
| [`Self_Assessment_Checklist.md`](Self_Assessment_Checklist.md) | Capability checklist across all twelve modules | At the end of the course, and before you accept your first paying engagement |

**Pass standard:** 70% overall on the practical exams and capstone rubrics, with the control checks in
your model returning zero. Understanding is the test — not file completion.

**How to mark yourself honestly:** for every number you cannot explain in plain language to a
colleague, deduct the points and rework it. A report you cannot defend is worse than no report.
